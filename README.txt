MOYO SURPRISE WEBSITE
=====================

MAIN WEBSITE FILE:
- index.html

ASSET FOLDER:
- assets/cover-flowers.svg
- assets/pink-roses.svg
- assets/heart-frame.svg
- assets/soft-bokeh.svg

HOW TO OPEN:
1. Extract the ZIP file.
2. Keep index.html and the assets folder together in the same folder.
3. Double-click index.html to open it in Chrome, Edge, or Firefox.
4. Internet is only needed for the optional Google Fonts. The illustrations work offline.

HOW TO ADD YOUR OWN PHOTOS:
1. Copy your photos into the assets folder.
2. Rename them photo1.jpg, photo2.jpg, photo3.jpg, photo4.jpg, photo5.jpg, photo6.jpg.
3. Open index.html in Notepad or VS Code.
4. In the gallery section, replace the six image src values:
   assets/cover-flowers.svg
   assets/pink-roses.svg
   assets/heart-frame.svg
   assets/soft-bokeh.svg
   assets/pink-roses.svg
   assets/cover-flowers.svg
   with:
   assets/photo1.jpg
   assets/photo2.jpg
   assets/photo3.jpg
   assets/photo4.jpg
   assets/photo5.jpg
   assets/photo6.jpg
5. Save the file and refresh the browser.

WEBSITE NAME / FOLDER NAME:
Moyo — A Little Love Story

You can rename the folder to: Moyo-Love-Story
Do not rename index.html unless you also update how you open it.
